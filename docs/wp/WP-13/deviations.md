# Afwijkingen WP-13

Geen enkele afwijking raakt een contract, schema, externe API, dependency of acceptatiecriterium buiten wat de review al noemde.

1. **Node-versie lokaal.** De machine had Node 25.8.2 (past niet in `engines` `^24.15.0 || >=26`, met `engine-strict`). Node 24.22.0 is via `fnm install 24` geinstalleerd en gebruikt voor alle web-commando's. Impact: geen.
2. **N-3 (R7, `pollInterval`).** SvelteKit's `version.pollInterval` staat standaard op 0, dus er is geen uurlijkse versiecheck. De bedoeling van R7 (uurlijkse check) is uitgevoerd door `version: { pollInterval: 3_600_000 }` in `sveltekit({...})` in `web/vite.config.ts` te zetten. De tekst van R7 in de blueprint is daarmee gecorrigeerd in gedrag; de blueprint zelf is niet aangepast. Let op: dit pollt `/_app/version.json` (same-origin, geen SW-interceptie, geen derde partij).
3. **N-9 (`shouldCreateUser: false`).** `signInWithMagicLink` roept `signInWithOtp` aan met `options: { emailRedirectTo, shouldCreateUser: false }` tot WP-22. Onbekende adressen krijgen geen rij in `auth.users`/`profiles`. Gevolg: A5 (open aanmelden) vervalt voorlopig; Lars moet zichzelf eenmalig aanmaken via het Dashboard (staat in RUNBOOK 9.2). Extra: foutcode `otp_disabled` (onbekend adres bij gesloten aanmelding) wordt in `authErrorMessage` naar `notAuthorized` gemapt; tests aangepast (`auth.test.ts`, `login.test.ts` verwachten het extra optieveld).
4. **Service worker: `resolve()` vervangen.** `resolve(asset.path)` uit `$app/paths` typecheckt niet (alleen getypeerde route-ids; de manifestpaden zijn zonder leidende slash, bv. `_app/immutable/...`). In `web/src/service-worker/index.ts` gebruik ik `new URL(path, self.registration.scope).pathname`. Zelfde resultaat bij lege `paths.base`.
5. **Env-onzekerheden kit 3.** Beide eerste keuzes werken: de relatieve import `./lib/env-schema.js` in `src/env.ts` laadt, en de build faalt met `env_invalid` plus de eigen melding bij lege URL en bij `sb_secret_`. Onder vitest zijn de placeholders in `vite.config.ts` aanwezig. Geen terugvaloptie nodig. `service-worker.js` heet inderdaad `build/service-worker.js`.
6. **Kleine extra's.** `test/helpers/fake-cache.ts` gebruikt de toegestane cast `as unknown as Cache`. In `Attribution.svelte` een lokale snippet `link` om herhaling te voorkomen (zelfde markup en teksten). RUNBOOK 9.3 noemt een terugvaloptie voor `NODE_VERSION` (review N-4).
